# Sqafe search intent map

**Research date:** 2026-11-15. **Canonical site:** <https://sqafe.com/>.
The public search brand is **Sqafe**; “SafeScan QR” remains visible in the current product UI.

## Evidence and limits

The starting phrase set came from [Google autocomplete](https://suggestqueries.google.com/complete/search?client=firefox&q=qr%20code%20safe) and [DuckDuckGo autocomplete](https://duckduckgo.com/ac/?q=qr%20code%20safe&type=list), with additional checks for “how to check QR code” and “quishing”. Suggestions are evidence that a phrase is used, **not** monthly search volume, ranking difficulty, or a ranking forecast. No verified Search Console property or query export was available. Do not invent volume or difficulty numbers. Revisit this map using real impressions and clicks after domain verification.

| Canonical URL | Primary search intent | Supporting phrases | Status |
| --- | --- | --- | --- |
| `/` | QR code safety checker (tool) | is this QR code safe; scan QR code safely; Sqafe; check a QR link | Indexable; scanner is the main tool. |
| `/learn` | QR code safety guide (informational) | what is quishing; QR phishing; how to inspect a QR code; malicious QR signs | Indexable; existing guide covers these topics. |
| `/contact` | Sqafe contact (navigational) | Sqafe support; report a security issue; privacy contact | Indexable; contact options are visible on the page. |
