Do not add `sameAs` for a site that merely mentions Sqafe or a directory listing whose identity is unverified. The current homepage schema intentionally omits `sameAs`. If the operating organization has a different name from the Sqafe product brand, identify each separately before adding organization-profile markup. The plan's proposed **H&R Devs** ownership statement was not verified and is not published on the site.

Do not create a Wikidata item to seed a knowledge panel. [Wikidata requires notability under its own policy](https://www.wikidata.org/wiki/Wikidata:Notability), and [Google creates knowledge panels automatically](https://support.google.com/knowledgepanel/answer/9787176). Neither can guarantee a panel or spelling-correction change.
