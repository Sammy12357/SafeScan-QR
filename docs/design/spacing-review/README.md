# Phase 2 spacing review

The Phase 0 screenshot harness captured the current main baseline and this branch in local mock mode. The 48 representative after images below are committed for PR review; the harness also captured all 49 views at 375, 768, and 1440 CSS pixels in both themes (294 images), with the complete output held under `.cache/ui-shots/phase2-full/`. Dynamic timestamps and generated content can differ between runs.

Spacing changes are small on public pages: in the eight representative views, full page height changed by at most 37 pixels. The admin dashboard grows 144 pixels on mobile and tablet because the navigation and cards use roomier scale values. No clipped elements or broken layouts were observed in the representative images.

## Reproduce

From the repository root with the pinned development dependencies and Playwright Chromium installed:

```sh
python scripts/ui_screenshots.py --app-root .
```

Phase 0 adds the harness to `scripts/ui_screenshots.py` before this migration is merged. It writes full captures under `.cache/ui-shots/<git-sha>/`.
