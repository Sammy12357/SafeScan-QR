Reproduce the before captures from a checkout of `0ae0867` with `python scripts/ui_phase6_before_qa.py --app-root /path/to/phase-6-base`. Reproduce the after captures and held-request assertions with `python scripts/ui_phase6_browser_qa.py` from the changed checkout. The scripts require Playwright and its Chromium browser from the development dependencies.

The browser assertions cover a held wallet provider connect, nonce request, verification request, provider disconnect, wallet status request, native scanner POST, and runtime request. Closing the wallet modal discards late outcomes; timeout states restore controls and present retry or unavailable copy. The Node regression checks account-isolated cache handling, failed wallet status, denied localStorage, authoritative restoration, and promise deadlines.
