# ASCII finder corner visual check

The [before captures](../ascii-motion-qr/README.md) show solid black finder corners. These after captures show all three corners with changing ASCII glyphs over the chosen gradient, while their white rings and QR border stay clear.

The page downloaded a [still PNG](ascii-motion-still.png) and [animated PNG](ascii-motion-animated.png). Both decoded to the input URL at native size and 320 px; all four exported animation frames also decoded. The 375 px page capture decoded as a whole image. [Motion frame A](motion-frame-a.png) and [motion frame B](motion-frame-b.png) differ. The browser reported no page errors. This is decoder evidence, not a physical camera scan.
