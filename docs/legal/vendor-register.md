# Outbound host and vendor register

Baseline: repository commit `a2ce01b`, reviewed 2026-11-15. This is a **code-path inventory**, not a claim that every optional integration is enabled in production, that a provider's contract permits a use, or that no other network traffic occurs. Render environment values, DNS/CDN configuration, browser network captures, package behavior and vendor agreements remain unverified. “Automatic” means a normal page or scan may contact the host without an additional vendor-specific click.

## Infrastructure, disclosures and follow-up

- Render hosts the application according to the deployment configuration, and the user reports Cloudflare DNS/domain service. The current code alone cannot establish the live hosting region, Cloudflare proxy status, log retention, subprocessors, or contracts. Add confirmed facts after reviewing the live account settings and agreements.
- The code imports/configures Anthropic and OpenAI keys and the Privacy Policy mentions those providers, but this audit found no outbound Anthropic/OpenAI API call in the current application. Do not claim either currently receives scanned URLs without a trace or code path. The current scanner also has no VirusTotal outbound call in the inspected code.
- CSP allowances are permissions, not evidence that a request occurs. Conversely, dynamic destinations (redirect tracing, WHOIS, configurable SMTP/RPC/storage) cannot be enumerated from literal URLs alone.
- For each active provider, record contract/terms, legal role, data categories, location, retention, transfer mechanism and production configuration before publishing a definitive privacy disclosure. Browser request capture should cover guest homepage, login, signed-in profile, scan, Go Ghost and payment flows. Review the register whenever a host or SDK is added.
